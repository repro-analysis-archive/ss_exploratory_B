Summary
  Without refitting the step-5 PCA / LEACE features, plan B evaluates site recoverability after the
  protocol LEACE in three nested evaluation sets (278 cases, all steps; the 158 primary cases, all
  steps; the 158 primary cases, analysis region), in a transport analysis (the step-5 E3 probe
  evaluated on each set) and a recoverability analysis (the same probe specification refitted within
  each set), each with the locked linear and MLP probes. It identifies where the E3-site judgement
  changes, not why, and changes no E3 gate, §13 ceiling, family verdict or protocol result.

Relation to the existing registration
  This is an addendum to the existing registration https://osf.io/5c627 (exploratory analyses X1/X2,
  plan commit b6d1cf7, embargoed until 2028-10-13). The existing registration and its files are not
  modified.
